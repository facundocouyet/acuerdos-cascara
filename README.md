# Fusión Cáscara — Acuerdos principales

Sitio interno de socios de Cáscara Collective con los acuerdos de la fusión Cáscara + F3 (Cáscara V4).

- **index.html** — portada con las dos piezas.
- **mapa.html** — el mapa de la fusión: tablero navegable de 6400×5500 (pan con scroll/arrastre, zoom con ⌘+scroll, `0` reencuadra).
- **documento.html** — el documento maestro completo, imprimible en A4.

Sitio estático publicado en GitHub Pages. Generado desde el handoff de diseño `design_handoff_cascara_v4`.
